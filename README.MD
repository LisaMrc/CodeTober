# 🎃 CodeTober — Card Generator

Inspiré par le célèbre Inktober, CodeTober est un challenge qui consiste à réaliser un projet de code par semaine à partir d'un prompt sur le thème d'Halloween. 🦇

Ce site permet de générer une carte personnalisée récapitulant les prompts, les projets, les langages utilisés et les liens vers les repo GitHub associés. La carte est destinée à être exportée au format SVG pour être partagée.

![Exemple de carte CodeTober](./images/codetober-2026-card-preview.svg)

## 🕷️ Fonctionnalités
- Carte dynamique mise à jour selon les informations saisies
- Génération aléatoire de prompts
- Affichage des projets, langages et liens GitHub
- Export SVG (en cours)
- Une direction artistique inspirée d'Halloween

## 🛠️ Outils et technologies
- **Tailwind CSS** - stylisation de l'interface
- **JavaScript vanilla** - logique et interactions
- **Vercel** - déploiement
- **Gitmoji** - commits (gitmoji.dev)

## 🎯 Objectif
Consolider mes bases en JavaScript en écrivant volontairement la majorité du code à la main. Claude Code m'a servi d'outil de brainstorming et d'apprentissage, notamment pour obtenir des explications, sans génération du code du projet.

**Notions JavaScript travaillées :**
- Variables, chaînes de caractères et booléens
- Types et comparaisons
- Conditions et boucles
- Tableaux et objets
- Fonctions et fonctions fléchées (ES6)
- Fonctions dépendant des valeurs reçues en entrée (mapping, lookup et valeurs par défaut)
